# Skill 采集与桌面设置修复

## 修改

新事件管线接入已有 Codex SkillReads 解析器。识别明确的 SKILL.md 读取调用并配对成功结果，按会话、轮次、规范路径生成稳定调用身份；同轮重复读取不重复计数。以 correlated 准确度上报读取证据，不把读文档等同于原生技能执行，也不伪造零时长。未执行、搜索提及及失败读取不计数。

解析器状态与文件游标一起持久化，支持调用和结果分处不同批次及重启恢复。仅涉及调用或会话上下文的记录恢复解析器，普通 Token 记录不解析 Skill 历史状态。全局技能可使用解析器筛选的公开名称，项目私有技能只上报 HMAC 身份，本地路径不进入上传数据。

悬浮球前后端默认尺寸统一为 96dp，已有有效尺寸偏好继续使用。移除重建卡片的说明段落，保留运行进度、确认操作和错误提示。

## 验证与交付

桌面 Rust 全量 285 项通过、11 项忽略；新增 Skill 管线专项通过，覆盖跨记录状态序列化、失败读取、同轮重复读取、全量重扫身份一致与公开名称边界。复用解析器原有 2 项测试通过；桌面前端构建通过。

仅代码修改，尚未发布桌面新版本或替换本机安装。旧游标之前的历史 Skill 需要安装修复版本后重建。异机用量差异按用户要求暂停，不将未拿到本地数据的推测认定为根因。
