# 本地 Dashboard 交互原型

状态：UI 评审稿；全部数据为固定设计样例，未连接真实账号、额度接口或采集进程。暂停/恢复与同步按钮只改变当前页面的示例状态。

打开 `index.html` 即可查看，不依赖 npm 或 CDN。也可在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765`。这个静态预览服务不是正式 CLI 本地 HTTP 服务；它只提供公开可提交的原型文件。

## 信息架构

| 页面 | 内容 | 参考实现 |
| --- | --- | --- |
| 总览 | 10 项指标、趋势、订阅额度、本机采集状态、Agent 构成、日历、Skill、个人排名提示 | Web `PersonalAnalytics.tsx` + 桌面 `UsagePanel.tsx` |

CLI 不提供悬浮球、托盘、桌面置顶、最小化到托盘、球体动画或相关设置。网页只展示运行相关内容；网页服务与后台采集生命周期独立。

## 已实现的原型交互

- 左侧四页切换；切换保留统计范围与周期。
- 全部设备/本机切换；设备页同步切换为三台/一台设备。
- 过去 24 小时、今日、近 7 天、近 30 天、全部时间；数值和趋势按样例联动。
- 趋势 Agent/模型筛选；不匹配时显示空状态，概览和额度不跟着趋势筛选变化。
- 额度异常说明弹窗、模型明细折叠、热力图日期详情、示例数据刷新。
- 设备页暂停/恢复采集、立即同步仅模拟状态，并明确提示未控制真实服务。
- 键盘焦点、Esc 关闭弹窗、窄屏导航和内容重排、减少动画偏好。

## 展示契约

1. 账号用量与本机未上传记录分开，不相加。本机订阅额度始终是当前工具账号的独立快照，不随统计周期或账号设备范围变化。
2. 保留桌面监控的“今日”，并与 Web 的“过去 24 小时”并列。今日为 UTC+8 自然日；正式接口需分别实现，不能把两种窗口混用或共用 API 参数。
3. 额度显示“已用”比例和重置时间；没有授权、过期和不支持分开。过期值只在详情中作为历史快照显示，不当当前值，不显示假 0%。
4. 当前阶段费用、模型、时长、日期及账号均为设计样例，不代表真实账单或工具实时能力。年度日历和排名有独立窗口说明。
5. 监控按钮属于新增的拟议产品交互。正式实现需要已认证的本地写 API、CSRF 防护与单一采集进程的 IPC/命令委托，不能由网页服务直接成为第二个写入者。

## 视觉规格

- 沿用现有个人页的浅色、绿色语义，页面底色 `#f5f7f3`，正文 `#243321`，强调色 `#bef172`；额度接近上限使用暖琥珀色，配明确文案。
- 字体优先 Avenir Next + 苹方；Windows 回退 Helvetica Neue/微软雅黑；可替换组合为 Source Sans 3 + Noto Sans SC。正式接入优先复用现有字体资源，不新增远程字体请求。
- 间距以 4px 为基础，常用 8/12/16/24/32px；页面标题 29px，主要数值 32–38px，区块标题 15px，正文和辅助信息按密度分级。
- 桌面侧栏 220px，内容按可用宽度伸缩；中屏侧栏收为图标，窄屏内容单列。卡片圆角 15–18px，分组依靠留白与细边框，不使用悬浮装饰。
- 页面有加载、未知、额度授权失效和无匹配趋势状态；后续正式实现应补充断网、未登录、服务退出和接口部分失败的真实状态切换。
