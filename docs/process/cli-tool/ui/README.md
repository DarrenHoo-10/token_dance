# 本地 Dashboard 交互原型

状态：UI 评审稿；全部数据为固定设计样例，未连接真实账号、额度接口或采集进程。首版 dashboard 按只读设计，页面上没有任何会改变真实采集服务的按钮。

打开 `index.html` 即可查看，不依赖 npm 或 CDN。也可在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765`。这个静态预览服务不是正式 CLI 本地 HTTP 服务；它只提供公开可提交的原型文件。

## 信息架构

| 页面 | 内容 | 参考实现 |
| --- | --- | --- |
| 总览 | 10 项指标、趋势、订阅额度、本机采集状态、Agent 构成、近 12 周活跃日历、Skill 摘要、个人排名 | Web `PersonalAnalytics.tsx` + 桌面 `UsagePanel.tsx` |
| 用量与额度 | 工具用量与费用、套餐、各额度窗口已用比例与重置时间、模型明细、其他来源 | 桌面 `QuotaRings`、`ModelUsageList`、来源列表 |
| 活动与技能 | 全年活跃日历（可用方向键浏览）、Skill 排行与已知成功、活动时长 | 桌面 `AnnualActivity` + Web 个人页 |
| 设备与同步 | 设备统计、本机运行时长、待同步/已确认记录、资源开销、同步动态、只读说明 | 设备页 + 桌面 `DaemonStatusCard` |

总览只放摘要（近 12 周日历、Skill 前 4、额度前 3 个工具），完整内容在对应页面，避免同一内容在多页整块重复。

CLI 不提供悬浮球、托盘、桌面置顶、最小化到托盘、球体动画或相关设置。网页只展示运行相关内容；网页服务与后台采集生命周期独立。

## 常驻状态栏

顶栏右侧的状态胶囊在所有页面常驻，显示采集运行状态，点击进入“设备与同步”；旁边显示数据最后获取时间。账号数据过期时时间变为琥珀色并写明过期时长。

## 状态演示

右上角“状态演示”下拉用于评审各状态，正式页面没有这个控件：

| 状态 | 表现 |
| --- | --- |
| 正常 | 默认 |
| 未登录 | 直接落在“本机”范围，“全部设备”不可选；顶部提示 `tokendance login`；排名不显示名次 |
| 首次使用，无数据 | 空状态说明，给出 `init` / `run` / `service install` 步骤；写明“没有记录”不是“用量为零” |
| 采集未运行 | 状态胶囊和状态条变琥珀色，显示上次采集时间和 `tokendance run`；已有本机数据照常展示 |
| 网络离线 | 账号数据标为快照并写明过期时长，不自动换成本机数据，提供“查看本机数据”入口 |
| 登录已过期 | 账号范围显示需要重新登录，本机范围不受影响 |
| 部分数据失败 | 只有趋势、Skill 面板显示失败与“重试”，其余照常 |
| 本地服务已断开 | 整页置灰并禁用交互，提示重新运行 `tokendance dashboard`，并说明 SSH 下启动链接只能兑换一次 |

## 已实现的原型交互

- 左侧四页切换（窄屏为底部标签栏）；切换保留统计范围与周期。
- 全部设备/本机切换；设备页同步切换为三台/一台设备。
- 过去 24 小时、今日、近 7 天、近 30 天、全部时间；数值和趋势按样例联动。
- 趋势 Agent/模型筛选，随筛选变化；不匹配时显示空状态，概览和额度不跟着趋势筛选变化；图下可展开数据表，供键盘和读屏使用。
- 额度异常说明弹窗、模型明细折叠、热力图日期选择、示例数据刷新。
- 热力图是单一 Tab 停靠点，方向键移动，Enter 选中；行为周一到周日，月份标签与列对齐。
- 键盘焦点、Esc 关闭弹窗、窄屏重排、减少动画偏好；重新渲染后焦点保持在原控件上。

## 展示契约

1. 账号用量与本机未上传记录分开，不相加。本机订阅额度始终是当前工具账号的独立快照，不随统计周期或账号设备范围变化。
2. 保留桌面监控的“今日”，并与 Web 的“过去 24 小时”并列。今日为 UTC+8 自然日；正式接口需分别实现（`range=day`），不能把两种窗口混用或共用 API 参数。
3. 额度显示“已用”比例和重置时间；没有授权、过期和不支持分开。过期值只在详情中作为历史快照显示，不当当前值，不显示假 0%。额度分三档：正常、80% 起琥珀、95% 起“即将用尽”。
4. 当前阶段费用、模型、时长、日期及账号均为设计样例，不代表真实账单或工具实时能力。年度日历和排名有独立窗口说明。
5. 环比变化有上升、下降、持平三种样式；下降不使用红色，避免把“费用下降”误读为异常。
6. 首版面板只读。暂停/恢复采集、立即同步需要本地写接口与 IPC，不在首版范围；设备页只显示对应命令。

## 视觉规格

- 沿用现有个人页的浅色、绿色语义，页面底色 `#f5f7f3`，正文 `#243321`，强调色 `#bef172`；额度接近上限使用暖琥珀色，接近耗尽使用砖红色，均配明确文案。
- 字号下限：辅助信息 11px，正文和标签 12px 起；不再使用 8–10px 文字。
- 对比度：所有文字与背景不低于 4.5:1（已在浏览器中对各状态逐个元素核对）；进度条、堆叠条色块与背景不低于 3:1；Agent 用四种色相和明度不同的颜色区分，同时始终配文字标签。
- 字体优先 Avenir Next + 苹方；Windows 回退 Helvetica Neue/微软雅黑；可替换组合为 Source Sans 3 + Noto Sans SC。正式接入优先复用现有字体资源，不新增远程字体请求。
- 间距以 4px 为基础，常用 8/12/16/24/32px；页面标题 26px，主要数值 32–38px，区块标题 15px。标题、范围、周期合并为一行，减少首屏占用。
- 桌面侧栏 220px，中屏侧栏收为带提示的图标栏，窄屏改为底部标签栏。卡片圆角 15–18px，分组依靠留白与细边框。
- 趋势图纵轴使用 1/2/2.5/5 的整齐刻度并按量级切换 K/M/B；窄屏减少横轴刻度。
