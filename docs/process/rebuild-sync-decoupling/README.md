# 重建、统计与上传解耦

状态：源码实现并完成本地回归；尚未发布。

## 问题

SQLite 更新时间排序可能在返回首行前超过 50 ms，旧代码随后直接终止批次，反复返回未推进的游标。统计每轮只处理有限任务，并与来源发现串行；上传已有独立循环，但能力接口返回 HTML 时被吞成 WAITING。生产 Nginx 缺少 v2 转发，测试环境已有对应路由。

## 实现

- SQLite 将首次返回行前的查询准备时间与逐行消费预算分开，保留条数和字节限制，过期时间预算仍允许首条推进；不会修改 harness 数据库或跳过原始记录。
- 统计从来源发现 tick 中拆出为常驻消费者。采集提交后通知统计；有任务继续处理，空闲每五秒补查。小时、日、月仍分别维护消费状态，单 writer 提交。
- 上传继续独立领取已入库事件，不等待重建或本地统计完成。能力接口异常、版本不兼容显示明确状态并自动重试，原始响应不写日志，失败不认领或确认事件。
- 手动清库仍通过生命周期写锁等待采集和统计任务退出，上传先等待在途请求；正常处理不持有独占生命周期锁。
- 生产 Nginx 增加 /token-dance/v2/ 转发。测试路由无需修改，不为桌面变更重发无关测试服务。

## 验证

回归覆盖过期查询预算的游标推进和幂等、未完成重建与统计期间仍可发起上传、错误能力响应后任务保留及恢复、持有来源发现锁期间统计仍能处理。另提供显式只读 SQLite 扫描诊断，禁止提交私人源数据和运行结果。

服务器只读核对：测试公开能力接口及两个环境的 API 内部能力接口返回协议 2，生产公开接口错误返回 HTML。候选 Nginx 配置已通过服务器 nginx -t，尚未替换线上配置。

验证结果：桌面 Rust 266 项通过、11 项条件测试默认忽略；前端 41 项测试及构建通过。SQLite 真实来源只读诊断已显式运行并到达 EOF，不写源库或运行中的事件库。候选生产 Nginx 配置通过云服务器 nginx -t，测试公开能力接口返回协议 2。
