## 改动

创作轨迹原先将返回的数据行等距排布。若只有前一天 23:00、当天 00:00、01:00、22:00 四条记录，21 小时的空档会被压成与 1 小时相同的宽度。现在按照实际时间排序和定位，刻度独立于记录行生成；跨天刻度显示日期，日/月粒度保留真实时间距离。无时区的桶时间使用服务端约定的 UTC+8，显式 ISO 时区按实际时刻换算。鼠标按真实横坐标选择最近记录，键盘仍可逐条访问；没有填造缺失记录或改动 Token 总量。
