# 过程文档

一个需求一个目录，记录从问题发现到验收的过程。分类边界见 [文档维护规则](../README.md)。

每个需求目录的 README 至少说明：需求目标、当前状态、相关文件入口，以及对应的项目事实和 spec。需要时添加调研、设计、实施、CR、验收和附件；简单需求无需拆多个文件。

需求结束后保留过程记录，并将最终实现更新到项目事实、将正式行为约定更新到 spec。中途放弃的方案保留为历史，不能继续作为当前规则引用。
