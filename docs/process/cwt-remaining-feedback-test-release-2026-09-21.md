## 改动及口径

延续现有绿色、圆角和页面结构，处理截图中的可用性、信息解释及布局问题。

1. 首页访客个人卡片新增“登录查看”，登录后返回个人数据；已登录入口明确为“查看我的数据”。导航栏固定提供搜索和我的数据两个动作，搜索从其他页面跳回榜单并聚焦输入框。
2. 密码占位符改为“请输入密码”。原来的不可点击同意声明改为通往现有“数据与隐私”文档的新窗口链接。仓库没有正式服务条款或隐私政策文本，本次未编造这类文档，也没有把说明文档称为正式协议。
3. 资料设置加载超过 15 秒会取消请求并显示重试入口；忽略超时请求迟到的结果，切换语言不重置尚未保存的输入。真实环境未复现原截图中的持续加载，所做修复是超时、失败恢复和竞态处理。
4. 首页“AI 交互”改为“模型请求”，增加单位和展开说明。后端该字段汇总的是 `model_request_count`；个人“总消息数”提示说明它是工具记录的消息与轮次事件，两者不等同。未改服务端统计或计费逻辑。
5. 个人数据弹窗使用固定关闭工具栏和独立内容滚动区；Agent/模型筛选使用可键盘操作的下拉列表。没有选项时禁用并解释，加载失败可重试；日历失败不再阻止筛选选项加载。长模型名换行，移动端菜单限制在弹窗可见范围内。
6. 首页收紧日历、统计卡片和留白，工具/模型/Skill 分布采用响应式列布局，完整显示长模型名。
7. 公开资料默认显示有数值的指标，其余收入“更多指标”，解释缺失值不代表零；不推断未同步或不支持。隐藏公开 Token 时同时避免从衍生指标推断其数值。个人数据缺失项分别提示首次同步、来源暂无数据或本周期暂无记录。
