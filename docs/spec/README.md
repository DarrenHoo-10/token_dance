# Spec

维护系统正式的行为、接口和数据约定，作为实现与验收依据。分类边界见 [文档维护规则](../README.md)。

每份规范说明适用范围、状态（草案／已确认／已废弃）、具体规则与验收条件，并链接相关实现事实和需求过程。涉及已有调用方或已存数据时，说明兼容性与生效条件。

规范描述系统应该怎样工作；实际是否支持、在哪个版本实现或部署，由项目事实记录。变更规范时更新原文件并保留 Git 历史，只有并存的协议版本需要独立文件。

## 规范索引

现有统计、事件、DDL 等资料尚待核对归位，见 [过渡入口](../README.md#现有文档过渡入口)。新增或迁入规范后在此登记主题、状态和适用范围。
