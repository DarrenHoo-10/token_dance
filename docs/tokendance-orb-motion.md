# 悬浮球运动与贴边收起

2026-09-06：替换悬浮球右键原生菜单。

- 右键按下记录弹弓锚点，向后拉时球体和光晕一起移动，松手从拉到的位置沿相反方向弹出。力度仅取决于相对锚点的拉动距离，按住时间不影响力度。拉距和发射力度不设上限；每拉动 1 DIP 增加 13.75 DIP/s 初速。界面显示持续增长的力度倍数，球体位置保持在工作区内，但蓄力计算保留完整鼠标位移。
- 原地按住、拉回锚点附近（4 DIP 内）不会发射；取消操作恢复按下时的位置。拉动阶段限制在当前屏幕工作区内，不触发贴边收起。
- 按实际经过时间积分，指数摩擦系数 1.0/s，碰撞后保留 74% 的法向速度。低于 25 DIP/s 停止。高速运动会反射越过边界的位移，支持一帧内多次碰撞，球体不会飞出屏幕。
- 自动运动在当前显示器工作区内只反弹，低速碰边或最终停在边缘均不收起，完整球体始终显示。
- 仅左键手动拖动后靠边松手（距边缘不超过 18 DIP）会收起，露出 20 DIP。单击收起部分只展开；完整球体必须双击才能打开主窗口，普通单击不打开界面。使用系统双击识别，拖动/取消操作不计入双击。按住左键可打断运动后重新拖动。
- 收起时使用原生圆形区域与显示器工作区求交，隐藏部分不显示、不拦截其他显示器的点击；外部光效同时隐藏。
- 收起/展开使用 240 毫秒的三次减速过渡，按真实时间推进。过渡期间球体和光效同步滑动并裁剪到原显示器工作区，结束后仅保留侧边露出的部分；中途点击从当前位置反向展开。帧循环固定使用该显示器的物理尺寸，不重复查询 DPI 或调整置顶层级。位置仅在过渡结束后保存一次，用量汇总在运动/拖动期间延后，避免卡住滑动。
- 左键拖出从收起时的实际位置计算鼠标位移，不先展开或移回屏幕。拉动期间沿用原屏幕的缩放与裁剪，球体和光晕完全露出后接续普通拖动；只拉出一部分就松手，会从当前位置平滑收回。按下会暂停正在进行的边缘动画，取消按压时恢复动画，点击展开仍沿用原来的 240 毫秒过渡。
- 取消指针捕获、失去焦点或隐藏窗口会取消尚未发射的蓄力；主窗口打开、关闭悬浮球或重建窗口会停止运动。

代码：`collector/apps/desktop/src-tauri/src/orb/motion.rs` 为可独立测试的物理模型；控制器在 UI 线程移动原生窗口，动画队列最多保留一个待执行帧；前端按手势顺序发送指令并合并拖动位置。

回归检查覆盖摩擦停止、高低速碰撞、四边露出面积、负坐标/高 DPI、不同帧率、非法输入、取消蓄力、点击与拖动区分、快速连续拖动，以及运动 IPC 仅允许悬浮球窗口调用。

移动时的外观同步：球体按目标显示器 DPI 保持正方形；光效窗口依据球体移动后的实际物理矩形计算位置和尺寸，不使用自己的 DPI 独立换算。圆形裁剪仅应用于顶层窗口，尺寸变化时重新生成，避免 WebView 子窗口保留旧裁剪。纯位移保留 WebView2 已合成的画面并明确禁止重复调整尺寸，只有实际尺寸变化才丢弃旧像素重绘；点击停止和自然停止时补一次原生重绘，避免高速运动停下后的空白间隙。每次移动都会恢复应显示的光效，贴边状态保持隐藏，展开时恢复完整圆形及光效。原生回归测试使用不可见窗口验证移动、缩放和裁剪恢复，不弹出测试窗口。

托盘菜单与主界面/设置页使用同一种语言，语言选择写入本地供下次启动使用。悬浮球开关开启时只显示“隐藏悬浮球”，关闭时只显示“显示悬浮球”；采集运行时显示“暂停数据采集”，暂停时显示“恢复数据采集”。菜单按状态变更更新，英文界面使用对应的单一英文标签。
